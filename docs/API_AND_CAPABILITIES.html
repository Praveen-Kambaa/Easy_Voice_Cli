Type Easy — API & Capabilities Guide

Complete reference for backend servers, third-party API keys, and on-device phone features used by the EVC / Type Easy Android app.

Project: EVC / Type Easy Config: src/config/api.js Updated: Jul 2026

1 Two backend servers

TYPE_EASY

https://easyvoice.kambaaincorporation.in/apiv2

Account, auth, cloud text translate, grammar check, usage / plan / tokens.

EASY_VOICE

https://easy-voice-api.kambaaincorporation.in/api

Voice STT, voice command (transcribe → execute), speech-translate, voice-server text translate.

Helpers: buildTypeEasyUrl() and buildEasyVoiceUrl() in src/config/api.js. Android mirror: ApiConfig.kt (generated at build).

2 What uses TYPE_EASY

Feature Endpoint Credential Where
Login / Register / OTP / Reset / Google Sign-In /auth/user-login, /auth/send-otp, /auth/verify-otp, /auth/complete-registration, /auth/google-signin, … Email/password, OTP, Google token AuthContext.js
Translate (cloud API path) POST /translate Form: user_id, text, target_language translationService.js; keyboard when internal translation is OFF
Grammar Check POST /grammar-check Form: user_id, text, fast Grammar screen; keyboard Grammar button
Usage / Plan / Tokens /usage/{userId}, /user-plan/{userId}, /update-tokens Optional Bearer login token typeEasyUsageApi.js, Profile

Login returns a user JWT stored by the app. Keyboard translate/grammar send user_id synced from the logged-in user — not a separate API key.

3 What uses EASY_VOICE

Feature Endpoint Auth in client Where
Voice Input (cloud) POST /voice/transcribe None Keyboard mic, floating mic (cloud), voiceApi.js
Voice Command /voice/transcribe → optional PUT /voice/transcript → POST /voice/execute None Keyboard / floating Voice Command; always cloud
Speech → Translate (cloud) POST /voice/speech-translate None Floating Translator when internal translation is OFF
Text translate (voice server) POST /voice/translate-text — textTranslationApi.js
History / Delete / Health /voice/history, /voice/delete/…, /health — voiceApi.js

Voice Command always uses Easy Voice (needs voiceAssetId for execute). The Internal Transcribe toggle does not apply to Voice Command.

4 Third-party API keys

These are separate from TYPE_EASY / EASY_VOICE. Values live in config files or Settings — this document lists purpose and location only.

Key Configured in Provider Used for
AI_PROVIDER_API_KEY src/config/aiProvider.js OpenRouter Ask Question chat completions (Bearer). Also synced to floating Ask mode.
AI_CHAT_API_BASE_URL + AI_CHAT_MODEL src/config/aiProvider.js OpenRouter (or compatible) Chat host + model id for Ask Question
TAVILY_API_KEY src/config/liveContextProvider.js Tavily Search Optional live web snippets before Ask
ElevenLabs API key Settings → AsyncStorage @elevenlabs_api_key ElevenLabs STT Cloud mic transcription when Internal Transcribe is OFF and a real key is set
Google webClientId AuthContext.js Google OAuth Google login → then Type Easy /auth/google-signin
Login Bearer token After login (app auth state) Type Easy backend Profile usage / plan APIs

No API key required

  • Datamuse word suggestions — https://api.datamuse.com/sug (public)
  • TYPE_EASY / EASY_VOICE voice clients — no Authorization header in current native/JS voice clients

Security: OpenRouter / Tavily keys in JS are for development. Prefer a backend proxy in production. Do not commit real production secrets publicly.

8 Mental model

TYPE_EASY → account + grammar + cloud text translate + usage EASY_VOICE → voice STT + voice command + speech-translate OpenRouter → Ask AI answers Tavily → optional live web context for Ask ElevenLabs → optional cloud STT when Internal Transcribe is off Phone OS → SpeechRecognizer, ML Kit, mic, IME, overlay, accessibility

9 Sample Easy Voice curls

Base: https://easy-voice-api.kambaaincorporation.in/api

1) Transcribe (Voice Input cloud / Voice Command step 1)

curl -X POST "https://easy-voice-api.kambaaincorporation.in/api/voice/transcribe" \
  -H "Accept: application/json" \
  -F "file=@/path/to/recording.m4a;type=audio/mp4" \
  -F "language=en-US" \
  -F "enablePunctuation=true" \
  -F "enableTimestamps=false"

2) Update transcript (Voice Command — only if user edited)

curl -X PUT "https://easy-voice-api.kambaaincorporation.in/api/voice/transcript" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{"voiceAssetId":"YOUR_ASSET_ID","finalTranscript":"Edited command text"}'

3) Execute (Voice Command)

curl -X POST "https://easy-voice-api.kambaaincorporation.in/api/voice/execute" \
  -H "Accept: application/json" \
  -H "Content-Type: application/json" \
  -d '{"easyVoiceAssetId":"YOUR_ASSET_ID","executeAt":"2026-05-29T10:15:45.123Z"}'
